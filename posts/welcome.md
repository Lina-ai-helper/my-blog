안녕하세요! 이 블로그는 **프레임워크 없이** HTML, CSS, JavaScript만으로 만들었어요.
글은 모두 마크다운 파일이고, 브라우저가 읽어서 바로 화면에 그려 줍니다.

## 새 글을 쓰는 방법

1. `posts/` 폴더에 `my-new-post.md` 같은 파일을 만들어요.
2. 파일 맨 위에 front matter를 적어요.
3. `posts/index.json`에 파일 이름(확장자 제외)을 추가해요.

front matter는 이렇게 생겼어요.

```markdown
---
title: 글 제목
date: 2026-09-21
tags: [일상, 개발]
description: 목록에 보일 짧은 요약
---
```

## 확인하는 방법

로컬 서버를 켜고 브라우저로 열면 돼요.

```bash
python3 -m http.server 8000
```

> 파일을 더블클릭해서 열면 글을 불러오지 못해요. 꼭 서버로 열어 주세요.

앞으로 자주 쓸게요. 😊
